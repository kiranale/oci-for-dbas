# Chapter 17 — Real-time migration issues and fixes

`migration_issues.csv` is the chapter's catalogue as one sortable file (52 entries, 10 areas): area, error or symptom, usual cause, fix.

Open it in a spreadsheet, filter by area or search for the ORA- code. Add your own rows in the same four columns — the next migration's catalogue starts from yours.

For any ORA- code not listed: `oerr ora <number>` on a database host.
